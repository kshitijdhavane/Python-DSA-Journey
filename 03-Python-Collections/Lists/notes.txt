##List comprehension 
- is a concise way to create a new list from an existing iterable, such as a list or a range(), optionally transforming or filtering its elements

Three ways to use list comprehension
A. Transform values
numbers = [1, 2, 3, 4]
result = [n * 10 for n in numbers]
# [10, 20, 30, 40]

B. Filter values
Use this when you want only elements that satisfy a condition.
numbers = [1, 2, 3, 4, 5, 6]
result = [n for n in numbers if n % 2 == 0]
# [2, 4, 6]

C. Transform based on a condition
Use this when you want every element to produce a value, but the value depends on a condition.
numbers = [1, 2, 3, 4]
result = [n if n % 2 == 0 else 0 for n in numbers]
# [0, 2, 0, 4]
