## String Immutability and Built-in Methods

word = "Hello Python"

print(word.upper())       # HELLO PYTHON
print(word.lower())       # hello python
print(word.capitalize())  # Hello python
print(word.title())       # Hello Python

These are particularly useful in coding problems.
Method	Purpose	Example
.isalpha()	Checks whether all characters are letters	"abc".isalpha() → True
.isdigit()	Checks whether all characters are digits	"123".isdigit() → True
.isalnum()	Checks whether all characters are letters or digits	"abc123".isalnum() → True
.isspace()	Checks whether all characters are whitespace	" ".isspace() → True
.islower()	Checks whether all cased letters are lowercase	"hello".islower() → True
.isupper()	Checks whether all cased letters are uppercase	"HELLO".isupper() → True

5. The DSA lesson to remember
The same technique can solve different problems depending on what you do with the pointers.
- Two pointers + swapping → reverse an array or list.
- Two pointers + comparison → check a palindrome.
- Two pointers + skipping unwanted characters → Valid Palindrome with spaces and punctuation.
- Two pointers + comparing adjacent or sorted elements → other array and string problems.
